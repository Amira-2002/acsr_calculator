Notes on the source sheet

  • 30/7 is missing from the increment table. Rows 9–25 have no 30/7 entry, and row 12 repeats 18/1. Choosing code G in the sheet would return #N/A. Here you can type the increment under Manual overrides.
  • Two grease cells are text. M42 and M44 hold "4,21" and "6,27" with comma decimals. The formulas read S9:AI12, which is numeric, so results are correct today, but anything pointing at H35:M51 would break.
  • The code and the wire counts are separate inputs in the sheet (D12 and D5/E5), so they can disagree. The dashboard reads the code from the wire counts.
  • Steel increment is looked up by steel wire count only (VLOOKUP(E5,J9:M25,4,0), first match). It works for the current table. The dashboard matches on aluminium and steel counts together.
  • Grease mass uses the steel wire diameter (D16 = K × E6²). For all-aluminium strandings with no steel, the aluminium wire diameter is used. Check this against the standard for strandings where the two diameters differ.
  • Column N ("Electrical Resistence") is unused in the sheet and equals the aluminium increment. It is used here as the resistance increment for the DC resistance estimate, which is an addition.
  • Rated strength follows C24:C31. Stress (MPa) ÷ 9.81 × 0.95 × CSA × 9.81 ÷ 1000, summed for aluminium and steel. The sheet types the stresses in (C24 = 165, D24 = 1310). The dashboard looks them up from the tables pasted in your sheet by wire diameter: aluminium Table I, steel Table III (regular) or IV (high strength). With your 3.2 mm aluminium and 3.0 mm steel wires this gives 165 and 1310 MPa, the same as the sheet, and a rated strength of 94.36 kN.
  • The sheet applies 0.95 to both metals using ultimate stress. The dashboard keeps that as the default. The "1% extension" option uses the steel stress at 1% extension from the same tables instead. Check which basis your edition of the standard or the customer specification requires.
  • The sheet calculates rated strength for one stranding at a time. The stranding table shows an RTS column using your current wire diameters and strength settings. The tables only cover wires up to 5.0 mm (aluminium) and 1.24 to 5.5 mm (steel); outside that, enter a stress under Tensile overrides.
  • D14 uses XLOOKUP, which needs Excel 2021 or Microsoft 365.
